01 / projects

Games & player tools 3

  • stream-able An OBS-like recording, livestreaming and multistreaming studio that runs inside Minecraft as a Fabric mod (MC 26.1.2 / 26.2 / 26.3), successor to Record-able. It adds RTMP/RTMPS streaming and multistreaming, interactive Chromium browser sources composited over gameplay, a microphone chain with optional local AI noise cancellation, and ultrawide support. Everything is driven from an in-game Studio screen (F6), and FFmpeg, the browser engine and models are downloaded on demand, pinned and SHA-256 verified. Java
  • vanillaamericamc Vanilla America+ is a client-mod-free Paper server project for Java and Bedrock cross-play. The repo holds the custom Paper plugin, a local operations portal, BlueMap integration, audited reports, a mock-only shop and a NixOS deployment module. Deployments default to loopback-only listeners and never accept the EULA, open public ports or enable live payments on their own. Java
  • nixpresence A VRChat OSC chatbox compositor with an optional Discord Rich Presence daemon, inspired by the ideas behind MagicChatBox but written independently under MIT. Providers such as MPRIS music and the focused window feed a shared state that is templated and sent to VRChat OSC, Discord or stdout. It includes doctor, preview and test commands and a systemd user service. Rust

Creative & AI media 4

  • ai-media-cli A local-first AI media CLI suite: Qwen-Image text-to-image and image editing, 3dai for a multi-stage TRELLIS.2 3D asset pipeline, and editvideo for SCAIL-2 character animation jobs. An ai-media doctor command checks environment, GPU and terminal-graphics support. Model weights are never bundled, and the shared preview/config tooling works without a GPU. Python
  • aivoice Local real-time AI voice conversion built on MeanVC2, exposed as a PipeWire virtual microphone. It searches community voice catalogs, downloads and validates voices, and builds reusable zero-shot MeanVC2 profiles from reference audio, including an honest RVC-to-MeanVC2 profile migration that does not pretend to convert weights. Usage requires an explicit consent acknowledgement. Python
  • deepfake A real-time face-swap CLI for research and VFX that wraps the AlphaFace research model. It adds an application shell around it: webcam and video capture, detect-swap-composite, presets and metrics, plus OBS-friendly outputs (preview, file, FFmpeg pipe, GStreamer, v4l2loopback virtual camera). A first-run consent notice and a synthetic-media watermark are on by default. Python
  • fakeperson A CLI for photorealistic fictional people with persistent synthetic identities (seed plus locked facial and style traits) rendered through a pluggable model backend. Safeguards refuse likely real-person or celebrity prompts and stamp every PNG as synthetic. A deterministic stub backend keeps it testable without a GPU. Python

Privacy & security 10

  • blurcam Native C++20 face privacy for Linux: YuNet face detection and optical-flow tracking with local blur, pixelation and glitch effects. It processes files through FFmpeg, previews with SDL, and outputs to a v4l2loopback virtual camera. No accounts, cloud inference, uploads or telemetry, and the docs are explicit that detection is fallible and offer a max-privacy preset and box masks. C++
  • privsec-tools The directory for a Linux-first privacy, security and OPSEC CLI toolkit. Every tool lives in its own independent repo; this umbrella indexes them with install commands and versions and optionally exposes a Nix package set. It states plainly that the tools improve hygiene and awareness but do not make anyone anonymous. Nix
  • opsec-check An umbrella, read-only privacy/OPSEC audit CLI for Linux covering network identity, VPN, DNS, MAC and more, optionally calling sibling tools (macrandom, mullvadctl, dnscheck, netidentity, metaclean, browserprivacy, fileshred) when installed. Findings are classed as informational, attention recommended or configuration issue, each with why it matters, and there is deliberately no fake privacy score. Output as text, JSON, Markdown or HTML. Rust
  • macrandom A Linux MAC-address randomizer with NetworkManager awareness. It lists interfaces with current and permanent MACs, randomizes fully or vendor-preserving, saves originals so they can be restored, and can set per-connection cloned MACs in NetworkManager. VPN, container, bridge and loopback interfaces are skipped by default, and the README documents what MAC randomization does not protect against. Rust
  • mullvadctl A companion CLI for the official Mullvad VPN client: status (relay, exit IP, location, DNS, IPv6, kill-switch hints), connect, relay rotation and relay browsing. check verifies connectivity and runs DNS-leak heuristics, and privacy-session snapshots state, optionally randomizes the MAC, connects, verifies and restores on exit. It never reimplements tunnel security and refuses to run without the official mullvad binary. Rust
  • dnscheck A DNS privacy analyzer that inspects resolv.conf, systemd-resolved, NetworkManager and Mullvad for likely leaks, fallback resolvers, VPN DNS bypass and split DNS. Passive by default, with optional active probes via dig/nslookup. Reports include JSON output and explicit statements of what cannot be detected. Rust
  • netidentity Captures a snapshot of a machine's network identity: hostname, interfaces, IPs and MACs, gateway, VPN, DNS, listening ports, firewall, Wi-Fi SSID and mDNS/UPnP hints. Snapshots are saved as JSON and can be diffed over time to spot changes. An offline mode skips the public-IP lookup, and secrets in free-form fields are redacted. Rust
  • metaclean A metadata inspector and scrubber for JPEG, PNG, WebP, HEIC, MP4, MOV, MP3, FLAC, WAV, PDF and Office files, surfacing GPS, timestamps, camera, author and software tags. It uses mat2 or exiftool when available and built-in Rust fallbacks otherwise. Originals are never overwritten by default: it writes a cleaned copy, and in-place mode makes a backup first. Rust
  • fileshred An honest secure-delete CLI: multi-pass overwrite and unlink on HDDs with non-CoW filesystems, and refusal without explicit acknowledgement on SSD/NVMe, Btrfs/ZFS, network or unknown storage. inspect reports the filesystem, mount options and rotational flag with advice, and explain spells out the limits of wear-leveling, TRIM, snapshots and backups. It never claims a file is guaranteed gone when the storage stack can't guarantee it. Rust
  • browserprivacy A read-only privacy auditor for Chromium-family and Firefox-family browser profiles on Linux, including Flatpak variants. It checks WebRTC, DNS-over-HTTPS, proxy mode, cookie policy, site permissions and extension inventories, and counts storage and service-worker entries. It never reads passwords, tokens, cookie values or credential stores. Rust

Desktop & terminal 5

  • MatrixShot A Wayland-native screenshot and screen-recording suite with a Matrix-themed Quickshell overlay. Select a region, then choose Screenshot or Screen Record; recording runs through gpu-screen-recorder with fps and audio options and an on-screen REC indicator. It includes an annotation editor (pen, highlight, rectangle, arrow, text) and uploads the last capture with host failover, copying the URL to the clipboard. QML
  • KeystrokeNoise Subtle mechanical keyboard and mouse click sounds for Linux, run as an evdev daemon across multiple keyboards. Key presses are mapped only to coarse categories (normal, space, enter, modifier, mouse buttons) and discarded immediately, so nothing about what you type is logged or transmitted. Configurable sound packs, a toggle command and a systemd user unit. Rust
  • matrix Realtime Matrix-style digital rain for the terminal, built on crossterm. Truecolor palettes with ANSI-256 fallback, presets, charsets and live controls for speed, density, palette and pause. Original glyph sets, XDG config, shell completions and a Nix flake. Rust
  • matrix-code-rain-sddm A Matrix-inspired SDDM greeter theme for Qt 6: dense Katakana code rain drawn live in QML behind a black-and-green login panel. No video or pre-rendered background, and it imports only QtQuick. The layout scales proportionally from 1080p to ultrawide and 4K, with username selection, masked password entry and a session picker. QML
  • vmtools A CLI/TUI suite for personal virtual machines: windowsvm and linuxvm on QEMU/KVM/libvirt, and androidvm on Docker-Android-Pro, under a vmtools umbrella. Commands cover doctor checks, VM creation from an ISO, interactive terminal menus and desktop entries. It defaults to the per-user libvirt session so disks stay in the user's data directory. Python
