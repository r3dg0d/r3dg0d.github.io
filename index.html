01 / about

I’m r3dg0d, a 24-year-old open-source software creator passionate about SI (Super-intelligence), Linux, privacy, and emerging technology.

I use an SI-native approach to software engineering, working with Claude Code, ChatGPT Codex, Google Gemini, SpaceXSI Grok Bot, Cursor, and other intelligent coding agents to turn ideas into functional open-source projects.

I run NixOS, experiment with new technology, and believe in building software that people can freely use, inspect, modify, and improve. I also have experience in the PS5 homebrew scene and in game modding.

02 / development workflow

SI-native means the coding agents are part of the everyday toolchain, like a compiler or an editor. I use them to brainstorm, plan architecture, prototype, implement, debug, refactor, optimize, test, and write documentation.

  1. 01IdeaA feature, tool, or experiment worth building.
  2. 02ArchitectureSpecs and technical direction, planned with agents.
  3. 03SI-assisted implementationAgents write and refactor code under my direction.
  4. 04TestingTests, running the real thing, and reviewing the diffs.
  5. 05IterationFix, refine, repeat.
  6. 06Open sourcePublished on GitHub for anyone to use and improve.
